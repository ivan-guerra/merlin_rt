# The Ray Tracer Challenge

This is an implementation of a basic ray tracer, following the book ["The Ray
Tracer Challenge"][1] by Jamis Buck. All the features described in Chapters 1-16
are included. This is an unoptimized implementation.

## Examples

You can run any of the examples in the `examples` directory. For example:

```bash
cargo run --example cover
```

That will produce a `cover.ppm` file in the root of the project. You can view
this file with any image viewer that supports the PPM format (e.g., `feh`).

[1]: https://pragprog.com/titles/jbtracer/the-ray-tracer-challenge/
